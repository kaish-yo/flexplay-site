FlexPlay プライバシーポリシー

最終更新日：2026年10月11日

FlexPlay（以下「本アプリ」）の開発者は、利用者の情報を収集するサーバーを運営していません。本アプリには、Android版と、PCのChromeで使う拡張機能版（以下「PC版」）があります。本アプリが扱う情報と、その保存先・送信先は次のとおりです。

端末内だけで扱う情報

  • 音声と画面：字幕を作るために、利用者が許可した場合に再生中の音声や画面を端末内で処理します。音声・画面を保存したり、開発者へ送信したりしません。
  • 字幕：生成した字幕は、巻き戻し時に再利用するため端末内に一時的に保存します。設定画面から削除できます。
  • 単語帳と復習の記録：登録した語、意味、例文、登録時の字幕の一文、復習の進み具合を端末内に保存します。
  • APIキーと設定：利用者が入力したAPIキーは、端末のキーストアで暗号化して保存します。

これらの情報は端末のバックアップ対象から除外しています。

PC版（Chrome拡張機能）で扱う情報

  • 動画の字幕：YouTube・Netflix・Prime Videoで作品を開いたとき、その作品の字幕（英語と日本語）を各サービスから取得し、画面に表示します。字幕は保存せず、ページを離れると破棄します。
  • 単語帳と復習の記録：Android版と同じ内容（登録した語、意味、例文、登録時の字幕の一文、復習の進み具合）を、このブラウザの拡張機能の保存領域に保存します。
  • APIキーと設定：利用者が入力したAPIキーは、このブラウザの拡張機能の保存領域にだけ保存し、YouTubeのページからは読めないようにしています。Chromeの同期機能では同期しません。PCには端末のキーストアに相当する仕組みがないため、暗号化はしていません。
  • 語句の解説：字幕の単語をクリックしたときだけ、その単語と字幕の一文を、利用者が設定画面で指定したAPIへ送信します。
  • PC版は、YouTube・Netflix・Prime Videoのページのうち、字幕・再生位置・再生速度の操作に必要な部分だけを扱います。閲覧履歴、視聴履歴、その他のページの内容を収集・送信しません。

利用者が設定したAPIへの送信

語句の解説や文の意味を調べる操作をしたときだけ、対象の文と語句を、利用者が設定画面で指定したAPI（例：OpenAI）へ送信します。送信先での扱いは、そのAPIの提供者の規約に従います。

Googleアカウントのデータ（単語帳の同期）

利用者が「Googleでサインインして同期」を選んだ場合に限り、本アプリはGoogleドライブの権限 https://www.googleapis.com/auth/drive.appdata を要求します。この権限で本アプリが読み書きできるのは、利用者のGoogleドライブ内にある本アプリ専用の非表示の領域だけです。利用者の他のファイルにはアクセスしません。

  • この領域には、単語帳と復習の記録（登録時の字幕の一文を含む）を、端末ごとのファイルとして保存します。同じアカウントでサインインした端末どうし（Android版とPC版を含む）で単語帳を同期するためだけに使います。
  • PC版では、Chromeにログインしているアカウントでサインインします。アクセス用の一時的な許可（トークン）はChromeが管理し、PC版は保存しません。
  • データは利用者本人のGoogleアカウントに保存され、開発者が受け取ることはありません。第三者に提供・販売せず、広告にも使いません。
  • 同期は設定画面（PC版ではサイドパネルの設定）でいつでもオフにできます。保存されたデータは、Googleドライブの設定の「アプリの管理」から本アプリのデータを削除することで消去できます。また、Googleアカウントの設定から本アプリのアクセス権を取り消せます。

本アプリによるGoogle APIから受け取った情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に準拠します。

その他

  • PC版を削除すると、ブラウザに保存された単語帳・設定・APIキーも削除されます。
  • 本アプリは広告を表示せず、開発者が利用状況を集める分析ツールも組み込んでいません。
  • 画面上の字幕の文字認識には、端末内で動くGoogleのML Kitを使います。認識する画像や文字はGoogleへ送信されませんが、ML Kitは動作状況や性能に関する情報をGoogleへ送信することがあります（ML Kitの利用規約）。
  • 本アプリが異常終了した場合の診断情報は端末内にだけ記録します。
  • 本ポリシーを変更する場合は、このページを更新します。
